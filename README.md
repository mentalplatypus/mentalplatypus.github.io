# mentalplatypus.github.io

My home page: ongoing projects and a portfolio of data visualization work.

**Live:** https://mentalplatypus.github.io/

The whole site is one `index.html` with no build step. To add an ongoing project, copy the `<article class="card feature">` block under "Ongoing projects" and change the picture, text and links. Portfolio cards follow the same pattern; set `data-glyph` on the card's `<svg>` to pick its little chart drawing (`stack`, `line`, `bar`, `paired`, `spine`, `bubble`, `scatter`, `box`, `choropleth`).
